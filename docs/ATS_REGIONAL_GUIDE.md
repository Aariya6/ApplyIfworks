# Regional CV / ATS profiles

This is a practical configuration guide, not a guarantee of ATS behavior. Employer systems differ.

## EU / international tech

- Prefer a single-column, text-first CV for ATS parsing.
- Use standard headings: Summary, Experience, Education, Skills, Projects, Certifications, Languages.
- Keep dates unambiguous and consistent.
- Put contact details in the document body rather than relying on headers/footers.
- Avoid graphical skill bars, decorative text boxes and image-only content.

## DACH / Germany

- A4 is the default.
- Clear education and experience chronology is useful.
- German-language applications should be generated only when the candidate can accurately support the language requirement.
- A portrait is configurable but never invented or required by this system.
- `GERMAN_APPLICATION` keeps the layout conservative and makes room for language and work-authorisation information.

## UK / broader Europe

- ATS_MODERN remains the safest default.
- Do not include unnecessary personal information.
- Preserve exact job-relevant terminology only when it is factually supported.

## AI tailoring rules

1. Match terminology, not facts.
2. Reorder existing evidence toward the role.
3. Never manufacture years of experience, employers, metrics, degrees or tools.
4. Never claim work authorisation that has not been approved by the candidate.
5. If the JD requires a qualification the profile lacks, mark it as a gap instead of fabricating it.
